# Dự án Node.js của Tôi

## Mô tả
Dự án này là một ứng dụng Node.js cơ bản.

## Yêu cầu
- Node.js >= 14.0.0
- NPM >= 6.0

## Cài đặt
1. Clone repository từ GitHub:
    ```bash
    git clone https://github.com/username/repo-name.git
    ```
2. Chuyển vào thư mục dự án:
    ```bash
    cd repo-name
    ```
3. Cài đặt các phụ thuộc:
    ```bash
    npm install
    ```

## Sử dụng
1. Khởi động ứng dụng:
    ```bash
    npm start
    ```
2. Truy cập ứng dụng tại `http://localhost:3000`.

## Cấu trúc Thư mục
- `src/`: Chứa mã nguồn chính của dự án.
- `public/`: Chứa các tệp tĩnh như HTML, CSS, JavaScript.
- `config/`: Chứa các tệp cấu hình.
- `tests/`: Chứa các bài kiểm thử.
